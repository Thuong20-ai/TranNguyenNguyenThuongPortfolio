# Thuong OS — Interactive Portfolio

Desktop-style portfolio of Tran Nguyen Nguyen Thuong (Digital Marketing, RMIT).
Single `index.html` + `img/` folder. No build step.

Publish on GitHub Pages: upload everything in this folder to the ROOT of a public repo
(`index.html` next to the `img/` folder), then Settings > Pages > Deploy from a branch > main / (root).
